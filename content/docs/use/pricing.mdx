Solrouter is sold as a monthly allowance of private calls. You pick a plan, pay in USDC on Solana, and each request to a private model uses one call. There is no per-token math.

## Plans

Every plan gets the same models and the same enclave. Bigger plans get more calls for each dollar.

| Plan | Price per 30 days | Private calls | Per 1,000 calls | Built for |
| --- | --- | --- | --- | --- |
| **Pro** | \$9 | 2,000 | \$4.50 | One person asking privately every day |
| **Builder** | \$49 | 12,500 | \$3.92 | Coding agents and small tools running all day |
| **Scale** | \$99 | 30,000 | \$3.30 | Products and teams sending real volume |

Every plan includes:

- All three private models: GPT-OSS 20B, Qwen 3.8 27B, and Qwen3 Coder 30B. See [Models](/docs/how-it-works/models).
- The MCP server and the TypeScript SDK. See [Integrations](/docs/integrations).
- A Solana receipt for each sealed call. See [On-chain proof](/docs/how-it-works/proof).

## Try it first

| Who | Free allowance |
| --- | --- |
| Signed-in user | 5 free messages |
| Guest, not signed in | 5 messages a day |

Sign in at [solrouter.com](https://solrouter.com) with an email address or a Solana wallet. There is no KYC. If you sign in with email and have no wallet, one is made for you.

## How you pay

- **USDC on Solana.** A plan is an on-chain subscription that renews every 30 days. You approve a bounded USDC amount for the plan, not an unlimited one, and you can cancel.
- **Card.** No crypto? Pay by card through MoonPay. MoonPay buys the USDC and sends it to your Solana wallet.

<Callout title="What counts as a call">
  One request to a private model is one call, whatever its length. Each call is capped at 8K tokens of context and 4K tokens of output. A call that fails on our side, for example while the enclave is down, goes back into your allowance.
</Callout>

## Agents without an account: x402

An agent that has no API key and no plan can pay for each request with [x402](/docs/glossary), settled in USDC on Solana mainnet. These prices come from `ROUTE_PRICES` in the backend, the same table that feeds the live manifest at [`/.well-known/x402`](https://api.solrouter.com/.well-known/x402).

| Route | USDC per call |
| --- | --- |
| `POST /api/v1/x402/chat/completions` (sealed inference) | \$0.02 |
| `GET /agents/v1/quote` | \$0.001 |
| `POST /agents/v1/swaps/oneshot` | \$0.10 |
| `POST /agents/v1/wallets` | \$0.05 |
| `POST /agents/v1/wallets/:id/fund-intent` | \$0.001 |
| `POST /agents/v1/wallets/:id/swap` | \$0.05 |
| `POST /agents/v1/wallets/:id/encrypt` | \$0.02 |
| `POST /agents/v1/wallets/:id/shield` | \$0.05 |
| `POST /agents/v1/wallets/:id/withdraw` | \$0.05 |
| `GET /agents/v1/wallets/:id/balance` | \$0.005 |

A plan covers inference only. Swap and wallet routes always charge their x402 price, so a plan's calls cannot be spent on swaps. See [Agent Privacy API](/docs/build/agent-privacy-api).
